# Everyday Things, Two Lines, Longer Run

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3-stdlib_only-green)](main.py)

A two-line explanation of rain for a 10-year-old, built on one vivid
analogy, with an honest second line about what that analogy maps and
what it leaves out.

Run `python3 main.py`; it writes the entry to `/output/entry.txt`.
Pure Python standard library only — the output is byte-identical on
every run.
